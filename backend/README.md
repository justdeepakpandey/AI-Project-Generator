#  AI Project Generator

An AI-powered full-stack web application that generates software project ideas using Google Gemini AI. Users can generate personalized project ideas based on their programming language, experience level, difficulty, and skills. Generated projects can be saved, viewed, and deleted using a MySQL database.

---

##  Features

-  AI-powered software project generation
-  Skill-based project recommendations
-  Save generated projects to MySQL
-  View all saved projects
-  Delete saved projects
-  Modern responsive UI
-  REST API using Express.js
